# 📊 Sales Data Analysis | Power BI

> An interactive **Sales Data Analysis Dashboard** built using **Microsoft Power BI** to analyze sales performance, identify trends, compare business metrics, and explore detailed order-level information.

---

## 🚀 Project Overview     

This project focuses on transforming raw sales data into meaningful and interactive business insights using **Power BI**.

The dashboard provides a clear view of sales performance through multiple analytical sections, helping users understand **sales trends, top and bottom performers, comparisons, and order-level details**.

---

## 📈 Dashboard Sections

### 1. Sales Trend Over Time

Analyze how sales performance changes over time and identify important trends and patterns.

### 2. Top 5 & Bottom 5 Analysis

Identify the **Top 5** and **Bottom 5** performers based on the selected sales metrics.

### 3. Comparison Analysis

Compare different categories and business dimensions to understand relative performance.

### 4. Order Details

Explore detailed order-level information for deeper analysis and business understanding.
